# WHAT THIS FILE IS
#   An authorised-sellers list. It tells ad buyers which accounts are allowed
#   to sell this app's ad inventory, so nobody else can pass off traffic as
#   yours. AdMob crawls it; without it, demand is reduced or withheld.
#
# BEFORE THIS FILE DOES ANYTHING — three conditions, all required:
#
#   1. REPLACE THE PLACEHOLDER BELOW with your real AdMob publisher ID.
#      Find it at apps.admob.com -> Settings -> Account information.
#      It looks like  pub-1234567890123456  (the literal prefix "pub-"
#      followed by exactly 16 digits). Keep the "pub-" prefix.
#
#   2. THIS FILE MUST SIT AT THE DOMAIN ROOT.
#      Google fetches exactly  https://<your-domain>/app-ads.txt
#      and nothing else. A GitHub Pages USER site serves the root:
#          https://sathoshimaking.github.io/app-ads.txt        <- works
#      A PROJECT site serves a subpath, which is never crawled:
#          https://sathoshimaking.github.io/ghost-access/app-ads.txt   <- ignored
#      That is why the repository must be named  sathoshimaking.github.io
#      exactly. See README.md in this folder.
#
#   3. THE SAME DOMAIN MUST BE YOUR APP'S MARKETING URL in App Store Connect.
#      Google reads the developer website from the App Store listing and then
#      looks for app-ads.txt on that host. If the listing points somewhere
#      else, or is blank, the crawl never happens. Set it to:
#          https://sathoshimaking.github.io
#
#   Crawling is not instant — allow up to 24 hours after the app listing is
#   live, and check AdMob -> Settings -> app-ads.txt for the verification
#   status. "Not found" almost always means condition 2 or 3, not this file.
#
